# 手机 APK 发布说明（网页"下载手机端"）

网页版左上角「下载手机端 → 安卓版」**直接从你的服务器下载 APK**，
不依赖蓝奏云等第三方网盘（蓝奏云跳转会触发微信拦截/举报提示）。

## 发布步骤（每次发新版只需要两步）

1. 用 Android Studio 或命令行编译正式版 APK（Release，带签名）；
2. 把编译好的 APK 文件**放进 `backend/static/` 目录**。

服务器会自动选择 `backend/static/` 里**最新（修改时间最晚）**的 `.apk` 返回，
**无需改代码、无需重启**——文件放进去立即生效。

## 目录与文件约定

```text
backend/static/                ← APK 放这里
└── 立洋社区-v1.0.1正式版.apk   ← 命名随意，但建议带上版本号
```

- 只放**当前要发布**的版本即可，旧包建议删掉（避免下载到旧版）；
- 文件名随意，接口按修改时间自动选最新的；
- 如果服务器用 git 部署，直接把 APK 提交到仓库（`backend/static/` 已随仓库提交）；
  也可以用 `scp` / 上传工具直接拷到服务器该目录。

## 验证

浏览器访问：

```text
https://你的域名/api/app-download
```

应直接开始下载最新 APK。后台「数据看板」的"手机端下载数"统计每次点击。

## 常见问题

- **下载到旧版本**：`backend/static/` 里可能还留着旧 APK，删掉只留最新版；
- **提示"安装包暂未上传"（404）**：`backend/static/` 目录是空的或没有 `.apk` 文件；
- **微信里下载被拦截**：微信内置浏览器可能拦截 APK 下载，点右上角「···」→「在浏览器打开」后下载。
