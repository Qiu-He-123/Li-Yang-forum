# 微信朋友圈同步客户端

负责把运营电脑上微信（PC 4.x）本机缓存的朋友圈增量搬运到立洋社区后端。

## 原理

- 微信一直登录，朋友圈页面保持打开/常下拉，数据会写入本机 `sns.db` 和图片缓存
- 本客户端每 10 秒增量扫描（按 tid 去重），**只上传**"已绑定且开启自动同步"的账号在开启时间之后的新动态
- 用户在程序里点「手动刷新」时，客户端只上传该用户近期朋友圈（默认最多 300 条，可配 manual_max_items）
- 未开启同步的用户、开启之前的旧动态一律不上传，杜绝全量搬运
- 后端判断发布者是否命中自动同步：是则自动发帖
- 每 10 分钟上报一次好友列表快照，用于用户"输入微信号/wxid 绑定"
- 用户在前端点"手动刷新"后，客户端下一次心跳会立刻扫描一次，然后恢复 10 秒节奏

## 使用步骤

1. 安装依赖：`pip install -r requirements.txt`
2. 双击 `启动同步客户端.bat`，会自动生成 `config.json` 并做解密自检
3. 按窗口提示配置：
   - `api_base`：后端地址（默认 `http://127.0.0.1:8000`）
   - `device_token`：先运行 `backend/scripts/init_wechat_sync.py` 查看令牌
   - `key_file`：`db_key.txt`（聊天记录导出工具生成）
   - `images_key`：`获取微信朋友圈/图片密钥.json`
4. 全部自检通过后点「启动同步客户端」

## 启动自检做什么

每次启动都会验证：朋友圈数据库能否解密、图片密钥能否解密真实缓存图片。
图片密钥按账号从本地 kvcomm 缓存推导（微信重启不影响，无需重抓）；
自检不通过通常是因为该账号还没有 V2 图片缓存，或密钥与账号不匹配，弹窗引导：
登录微信 → 打开朋友圈点开浏览 2-3 张图片（保持一张打开）→ 运行「获取图片密钥.py」→ 重新检测。

## 说明

- 扫描的是"运营账号能看到且已缓存的"朋友圈，不是任意人的全部历史
- 自动同步只同步用户开启自动同步之后发布的内容（后端按时间分界线过滤）
- 客户端只负责搬运，业务判断（绑定/同步/发帖/扣金币）全在后端
