# fail2ban 部署说明（立洋社区）

fail2ban 运行在宿主机，读取 nginx 容器日志，自动封禁高频/恶意 IP。正常用户无感知，不需要验证码。

## 1. 前提：日志已落盘

`deploy/docker-compose.yml` 已把 frontend 容器的 `/var/log/nginx` 挂载到宿主机 `logs/nginx/`。
启动后确认 `logs/nginx/access.log` 与 `logs/nginx/error.log` 存在。

## 2. 安装 fail2ban（Ubuntu/Debian）

```bash
sudo apt update && sudo apt install -y fail2ban
```

## 3. 复制配置

```bash
sudo cp deploy/fail2ban/filter.d/* /etc/fail2ban/filter.d/
sudo cp deploy/fail2ban/action.d/* /etc/fail2ban/action.d/
```

## 4. 启用 jail

把 `deploy/fail2ban/jail.local` 的内容追加到 `/etc/fail2ban/jail.local`，
并把日志路径改为宿主机绝对路径，例如：

```ini
[nginxrepeatoffender]
logpath = /opt/立洋社区/logs/nginx/access.log

[nginx-limit-req]
logpath = /opt/立洋社区/logs/nginx/error.log
```

注意：

- `nginxrepeatoffender`：一周内产生 444/403 超过 20 次 → 封 1 天。
- `nginx-limit-req`：一旦 error.log 出现 nginx 限流记录即封禁，偏激进；怕误伤正常用户可把该 jail 的 `enabled` 改为 `false`。

## 5. 重启并验证

```bash
sudo systemctl restart fail2ban
sudo fail2ban-client status nginxrepeatoffender
```
